### New

- You can connect AI apps to Journal online, without installing anything. Add `https://mcp.cloudx.run/journal` as a remote MCP server and sign in with your Homebase identity. This is a beta. It is free during the beta, with fair-use limits.
- The Agents page shows how to connect Claude Desktop, Claude Code, Cursor, Codex CLI and Hermes Agent. Each app has an Online option and a Local option. Cursor has an "Add to Cursor" button.

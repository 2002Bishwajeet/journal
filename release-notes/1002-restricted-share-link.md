### New

- The Share dialog has a Copy link button for a note that is not public. The link opens the note for the people you shared it with. Other people see "You don't have access to this note".

### Changed

- A share link for a note that does not exist shows "Note not found". A link for a note that is not public shows "You don't have access to this note", with a Sign in button when you are not signed in.

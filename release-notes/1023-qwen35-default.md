### Changed

- The assistant uses a new default model, Qwen3.5 2B. It does more note edits correctly than Qwen3 1.7B.
- Settings → AI shows Qwen3.5 4B as "Higher quality". It is more accurate, but it is slower and uses more memory.
- If you use Qwen3 1.7B now, the assistant continues to use it. You do not have to download a new model. To change the model, go to Settings → AI.
- Before a model for the assistant downloads, the dialog shows how much memory the computer needs.
- If the assistant model does not load because the GPU does not have sufficient memory, the assistant tells you which smaller model to try.

# Release notes for the next version

A PR with a change that users can see adds one file here, named after its branch or issue (for example `783-dialogs.md`). Do not edit `RELEASE_NOTES.md`: two PRs that edit it at the same time conflict.

The file holds one or more sections and their bullets:

```markdown
### Fixed

- On a phone, the buttons in a dialog stay above the keyboard.
```

Use only `### New`, `### Changed` or `### Fixed`. Write in ASD-STE100 Simplified Technical English (the rules are at the top of `RELEASE_NOTES.md`).

Manual Release puts all the files here under the new version in `RELEASE_NOTES.md`, deletes them, and stops if there are none.

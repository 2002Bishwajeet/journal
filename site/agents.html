Give your agents a notebook

The Journal MCP server lets Claude Code, Claude Desktop and Codex CLI read, search, create and edit your notes, in the folders you grant.

Paste into Claude Code, with your own identity in place of you.dotyou.cloud.

/plugin marketplace add 2002Bishwajeet/journal
/plugin install journal@journal
/journal:login you.dotyou.cloud

From a checkout of the repo, sign in once with npm run mcp:login -- you.dotyou.cloud, then add this to ~/.codex/config.toml:

[mcp_servers.journal]
command = "npm"
args = ["--prefix", "/absolute/path/to/journal", "run", "--silent", "mcp"]

From a checkout of the repo, sign in once with npm run mcp:login -- you.dotyou.cloud, then add this to claude_desktop_config.json:

{
  "mcpServers": {
    "journal": {
      "command": "npm",
      "args": ["--prefix", "/absolute/path/to/journal", "run", "--silent", "mcp"]
    }
  }
}

The MCP setup guide covers headless sign-in over SSH and every tool in detail.

Connect in three steps

  1. Run the commands above, with your own identity in place of you.dotyou.cloud.
  2. Approve ‘Journal MCP’ in your Homebase owner console, then run /mcp to reconnect.
  3. In Journal, open Settings → Agent access and grant the folders it may use.

Ask for a page, get a page

An agent can write live blocks straight into a note: a React chart or a Mermaid diagram that runs where you read it.

It makes small edits too, changing one passage with replace_in_note and leaving the rest of the note as it was.

  • Create a note called Standup in my Work folder with today's summary.
  • In my Trip plan note, change the flight time from 9:40 to 10:15.
  • Redesign my Trip plan note as a day-by-day itinerary.
  • Use ~/Pictures/lisbon.jpg as the cover of my Trip plan note.

Access, folder by folder

In Settings → Agent access, set each folder or note to None, Read, or Read + write. Everything starts at None, and you grant what each agent needs.

  • Private notes stay private. Mark a note ‘exclude from AI’ and it stays yours alone, whatever its folder allows.
  • Its own registration. The MCP server signs in as its own app on your identity, apart from the Journal web app, so you can revoke it on its own under Apps in your owner console.
  • Grants are checked on your computer. The MCP server reads your grants and filters every tool call by them, in its own process where it runs.

Fourteen tools, in three kinds

Write tools need Read + write access. Every edit is merged into the note's current state, so what you type at the same time is kept.

Read

list_folders
The folders you've granted.
list_notes
Granted notes, newest first.
get_note
One note as markdown, or as a list of blocks.
search_notes
Search titles, tags and text of granted notes.
get_authoring_guide
Everything a note can hold, and how to write it.

Write

create_note
A new note from markdown, in a writable folder.
append_to_note
Add markdown to the end of a note.
replace_in_note
Change one exact passage.
update_note
Rewrite the body, title or tags.
edit_block
Change one block, or one table cell, row or column.
set_note_cover
Set a cover image, with a dark-mode one beside it.
clear_note_cover
Remove a cover.

Organise

create_folder
A new folder the agent can write in. Revoke it like any other grant.
delete_note
Move a note to Trash, where you can restore it.

Edited notes are labelled with the agent that changed them, such as agent:claude-code.

Then publish what it built

Live blocks an agent writes keep running when you publish the note as a public page, for anyone with the link.
